# Reading message warnings

MyMail displays server-computed phishing warnings above a message. These can flag failed sender authentication, misleading sender names or lookalike domains, replies directed to another domain, deceptive links, risky attachments, and a sender you have never emailed. An absence of warnings does not mean the message is safe.

The sender's name and actual address appear separately. Internationalized domains display both decoded and ASCII forms. The sender address stays visible when you collapse the header.

Message body links remain plain text. A deceptive-link warning shows the displayed text and actual destination so you can compare them.

Reply and Reply All show a note when the server flags a Reply-To address on another domain. Check the recipient before sending.

Risky attachments are marked and require confirmation before opening. Blocked file types cannot be opened, even with confirmation.
